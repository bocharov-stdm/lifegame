# Tiny Life Simulation

Эволюционная симуляция: растения, травоядные и хищники в двумерном мире.
У травоядных есть геном из 7 генов — размер, скорость, зрение, порог
размножения, доля энергии потомку и вертикальный слой обитания (`min_y`,
`max_y`). Гены мутируют при делении, отбор идёт сам собой.

Требуется Python 3 и `pygame`:

```
pip install pygame
```

## Запуск

```
python main.py
```

Откроется главное меню, за ним идёт живой мир. Дальше:

- **Новый мир** — стартовые условия и правила, потом «Начать».
  - Вкладка «Мир»: сид, число травоядных и хищников, рост растений,
    скорость и зрение хищников.
  - Вкладка «Лаборатория»: правила мира — сила мутаций, энергия растения,
    цена статов и крутизна этой цены, плодовитость и запас энергии хищников.
    Опыты могут сломать баланс, в этом и смысл: при крутизне цены размера 1.0
    размер за 4000 тиков раздувается с 40 до восьмисот.
  - Одинаковый сид и настройки дают один и тот же мир. Чтобы повторить
    удачный, выключите «Новый сид при каждом старте».
- **Настройки** — полный экран, масштаб интерфейса, сглаживание, FPS.
- **Как играть** — управление и коротко об устройстве мира.

Настройки запоминаются в `user_settings.json` рядом с `main.py`. Файл можно
удалить — вернутся значения по умолчанию.

### Экран игры

Слева мир, справа панель:
- **Заголовок и управление:** номер мира, тик, кнопки темпа.
- **Численности:** счётчики трёх видов.
- **Графики:** две вкладки.
  - «Популяции» — численности трёх видов; наведите курсор, чтобы увидеть числа.
  - «Геном» — средний геном по генам: значение и изменение от начала партии.
- **Карточка существа:** появляется, когда существо выбрано.

Графики показывают последние 3000 тиков или всю партию. На «Популяциях» каждая
линия нормирована на свой максимум: хищников в разы меньше, и на общей шкале их
линия легла бы в ноль. А смысл графика — видеть, как пик хищников запаздывает
за пиком травоядных.

Когда вымирают хищники или травоядные, появляется заметка. Когда угасает вся
жизнь, появляется карточка с пиками численности. Если существ больше 3000,
партия встаёт на паузу: дальше окно начнёт тормозить.

### Управление

| клавиша | действие |
|---|---|
| Пробел | пауза / продолжить |
| → | один тик, пока стоит пауза |
| `+` / `-`, `1`…`6` | скорость: 1, 2, 4, 8, 16, 32 тика за кадр |
| колесо мыши | приблизить к курсору |
| перетаскивание, WASD | сдвинуть вид |
| Home | показать весь мир |
| ЛКМ | выбрать существо: его геном, энергия и сравнение со средним |
| ПКМ, клик мимо | снять выбор |
| F | камера следит за выбранным |
| G | график: популяции / геном |
| Tab | скрыть панель |
| F11 | полный экран |
| Esc | меню паузы: заново тот же мир, новый мир, настройки, выход |

Окно не зависает при любой численности. На тики уходит не больше 12 мс из
16.7 мс кадра, и если заданная скорость не укладывается, панель пишет
«не успевает», а партия просто идёт медленнее.

## Подбор баланса без окна

Симуляция отделена от отрисовки: логика живёт в пакете `life/`, а
`life/headless.py` умеет гонять её без дисплея. Это на порядок быстрее
наблюдения на экране и не требует графики вообще.

```
python sim_report.py                                   # прогон по умолчанию
python sim_report.py --seeds 1 2 3 --ticks 3000        # сводка по нескольким
python sim_report.py --predators 20 --predator-speed 18 --predator-vision 800
python sim_report.py --rule plant_energy=80 --rule size_power=1.5   # правила «лаборатории»
```

Отчёт показывает траекторию популяций, пики, средний геном и мс/тик.
Любой прогон ограничен четырьмя лимитами (тики, потолок популяции, бюджет
вычислений, дедлайн), поэтому зависнуть не может.

## Тесты

```
python -m unittest discover tests
```

76 тестов, около трёх секунд, окно не требуется.

- **Тесты приложения** (`tests/test_app.py`) рисуют в память через SDL-драйвер
  `dummy`. Они проходят экраны по кадрам синтетическими нажатиями и проверяют
  раскладку на разных размерах окна и масштабах. Без pygame часть из них
  пропускается.
- **Тесты движка** (`tests/test_simulation.py`) помимо регрессий на
  исправленные баги сторожат поведение популяции: взрыв численности,
  вымирание и обвал производительности.

## Устройство

Проект разложен по одному правилу: **`life/` — движок, он ничего не знает про
экран; в корне лежит слой приложения** — окно, отрисовка и CLI-отчёт.

| файл | что делает |
|---|---|
| `life/config.py` | все настройки; там же объяснено, почему они такие |
| `life/rules.py` | правила мира, которые можно менять без правки конфига |
| `life/world.py` | состояние мира и один логический тик |
| `life/grid.py` | сетка соседей: кому кого видно |
| `life/plant.py`, `life/vegetarian.py`, `life/predator.py` | сущности |
| `life/genome.py` | геном травоядного: имена генов и их подписи |
| `life/headless.py` | прогон без окна, с лимитами |
| `main.py` | точка входа |
| `app/settings.py` | что можно настроить, пределы слайдеров, файл настроек |
| `app/session.py` | идущая партия: темп, события, конец игры |
| `app/history.py`, `app/camera.py` | история для графиков; зум и слежение |
| `app/render.py`, `app/widgets.py`, `app/theme.py` | отрисовка, элементы управления, палитра и шрифты |
| `app/scenes/` | экраны: меню, новый мир, настройки, справка, игра |
| `app/app.py` | окно и переключение экранов |
| `sim_report.py` | отчёт для подбора баланса |
| `tests/` | безэкранные тесты движка и приложения |
| `Relict/` | **памятник 2025**: архив ранних прототипов, не редактируется |

Граница между `life/` и отрисовкой не на честном слове: тест
`TestLayering.test_engine_does_not_import_pygame` падает, если импорт `life/`
снова начнёт тянуть pygame. Логика приложения (`settings`, `session`,
`history`, `camera`) тоже обходится без pygame, и это тоже проверяется.

## О балансе

Ключевая идея в `life/config.py` — показатели степени в стоимости статов.
Цена стата должна расти круче, чем выгода от него, иначе эволюция качает
его до бесконечности: радиус поедания равен размеру (выгода ~ размер²),
радиус поиска еды равен зрению (выгода ~ зрение²), поэтому цены заданы как
`размер ** 2.5` и `зрение ** 2`.

Текущие значения проверены прогонами по 4000 тиков на два десятка сидов: обе
популяции доживают до конца, есть заметные колебания «хищник — жертва», а
численность держится в играбельном коридоре.

Растения ограничены потолком `PLANT_MAX`. Растение исчезает, только когда его
съели, так что в мире без травоядных они копились бы бесконечно. В здоровом
прогоне потолок не достигается никогда: пик — меньше трёхсот растений при
потолке 1500.

## О производительности

Существо интересуется только тем, что попало в радиус его зрения, но раньше
перебирало ради этого весь мир — и такой перебор случался четырежды за тик.
Стоимость росла как «травоядные x растения».

Теперь соседей выдаёт `life/grid.py`. Сущности при этом остались наивными: они
по-прежнему просто перебирают всех, кого им дали, — просто дают им теперь не
весь мир, а соседей по клетке. Индексацией занимается `life/world.py`.

| | было | стало |
|---|---|---|
| обычный прогон | 2.7 мс/тик | 0.7 мс/тик |
| нагрузка 400 существ / 400 растений | 18.6 мс/тик | 3.0 мс/тик |

Кадр игрового экрана рисуется за 1–3.5 мс из 16.7 мс, в том числе при
1500 травоядных и 1500 растениях (2.9 мс): отрисовка отсекает всё, что вне
вида, а надписи и графики кэшируются.
