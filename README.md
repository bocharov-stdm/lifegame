# Lifegame

Эволюционная симуляция: растения, травоядные и хищники в мире 40000×20000.
Геном наследуется и мутирует, отбор идёт через энергетический баланс — за размер,
скорость и зрение каждый платит из одного бюджета.

## Запуск

```bash
pip install -r requirements.txt
python -m lifegame
```

Управление: `Space` пауза, `+`/`-` скорость, `G` графики, `M` следующий ген на
графике, `S` экспорт истории в `run_<seed>.csv`, `R` рестарт с тем же сидом,
`Esc` выход. Сид показан в заголовке окна; чтобы прогон был воспроизводимым,
задайте `RANDOM_SEED` в `lifegame/config.py`.

## Структура

```
lifegame/     код игры
tests/        тесты
tools/        служебные скрипты
```

| файл | назначение |
| --- | --- |
| `lifegame/config.py` | все параметры, включая таблицу генов `GENES` |
| `lifegame/organism.py` | общая база: геном, слой обитания, шаг, метаболизм, мутация, деление |
| `lifegame/vegetarian.py` | травоядное: поиск растений, бегство от хищника |
| `lifegame/predator.py` | хищник: охота и переваривание |
| `lifegame/plant.py` | растение (плотность падает с глубиной) |
| `lifegame/spatial.py` | сетка для поиска соседей |
| `lifegame/world.py` | тик мира, без pygame |
| `lifegame/stats.py` | история прогона, графики, экспорт CSV |
| `lifegame/render.py` | окно, ввод, рендер |
| `lifegame/__main__.py` | точка входа для `python -m lifegame` |
| `tools/calibrate.py` | headless-прогон для подбора баланса |

`lifegame/__init__.py` намеренно пуст: калибратор подменяет значения в
`lifegame.config` до импорта симуляции, а модули читают их в момент импорта, так
что любой импорт `world` или `render` из `__init__` молча сломал бы этот механизм.

## Модель

**Геном** описан таблицей `GENES` в `lifegame/config.py`: имя, базовое значение, тип
мутации и границы. Мультипликативная мутация — для величин, где осмысленно
относительное изменение (размер, скорость, зрение); аддитивная — для процентных
генов, иначе значение 0 навсегда заперто в нуле.

**Энергия.** Расход за тик = `SIZE·size^1.5 + SPEED·speed² + SIGHT·vision + BASAL`.
Растение даёт фиксированную энергию, добыча — энергию жертвы плюс её биомассу.

**Слой обитания.** Гены `min_y`/`max_y` задают вертикальный коридор. Он
ограничивает и движение, и питание — иначе отбор по биомам размывается.

**Устойчивость хищник–жертва** держится на двух механиках:

* жертва видит дальше, чем хищник, и успевает убежать — иначе хищничество
  детерминированно;
* переваривание (`PREDATOR_DIGEST_TICKS`): сытый хищник не охотится. Это
  функциональный отклик Холлинга II типа, ограничивающий добычу сверху при любой
  плотности жертв. Без него окно между «хищники вымерли» и «жертвы уничтожены
  полностью» практически нулевое.

## Тесты и калибровка

Обе команды запускаются из корня репозитория:

```bash
python -m pytest -q
python tools/calibrate.py --ticks 20000 --seeds 12345,777,2024
```

Проверено: сиды 12345, 777 и 2024 по 20000 тиков и сид 12345 на 60000 тиков —
вымираний нет ни в одном прогоне. Режим колебательный, а не стационарный:
средние за прогон — растения 70-320, травоядные 450-720, хищники 60-340, с
пиками заметно выше. Широкий разброс между сидами здесь нормален.

## Видно ли эволюцию

Да, и это главная проверка того, что модель работает. Прогон на 40000 тиков
(сид 12345, средние по популяции):

| тик | травоядные | | | хищники | | |
| --- | --- | --- | --- | --- | --- | --- |
| | скорость | зрение | низ слоя | размер | скорость | низ слоя |
| 500 | 23 | 1961 | 50 | 119 | 32 | 60 |
| 20000 | 37 | 929 | 31 | 117 | 35 | 60 |
| 40000 | 44 | 762 | 31 | 165 | 24 | 61 |

Травоядные вдвое ускорились, вдвое урезали дорогое зрение и отступили в верхний
слой; хищники, наоборот, выросли в размере и замедлились — крупное тело держит
больший запас энергии и переживает паузы между добычей. Это и есть та самая
коэволюционная гонка, ради которой стоило давать обеим сторонам общий геном.

Калибратор принимает переопределения параметров, не трогая `lifegame/config.py`:

```bash
python tools/calibrate.py --ticks 12000 PLANT_SPAWN_RATE=4 PREDATOR_DIGEST_TICKS=300
```
